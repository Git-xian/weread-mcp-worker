# 部署到自己电脑（跑 Node 版）

> 适用：想让数据**完全不出本机**，或先本地跑通再上 VPS。
> 用的是仓库里的 **`server/`（Node 版）**，不是 Cloudflare Workers 版。
> 优点：真实阅读数据只过你自己的机器（贴合项目隐私红线）；缺点：电脑关机/休眠就断开。

---

## 0. 前置

- 装了 Node 18+（推荐 20/22）：`node -v` 能打印版本即可
- 你的微信读书 `wrk-` key
- 想给手机用的话：手机和电脑**同一局域网**（或下面配内网穿透）

---

## 一、本机跑起来

### Windows

```powershell
cd weread-mcp-worker\server
npm install

# 把 .env.example 复制成 .env，填两个值
copy .env.example .env
notepad .env
```

`.env` 里填：

```
WEREAD_API_KEY=wrk-你的key
MCP_AUTH_TOKEN=你自己定的一串随机口令
PORT=8787
HOST=0.0.0.0
```

> 本机直跑时 `HOST=0.0.0.0` 才能被同局域网手机访问；只想自己电脑用就填 `127.0.0.1`。

启动：

```powershell
npm run start:env      # Node 20.12+ 会自动读 .env
# 若 Node 版本较低，改用：
# $env:WEREAD_API_KEY="wrk-..."; $env:MCP_AUTH_TOKEN="..."; npm start
```

看到这样的输出就成了：

```
[weread-mcp] 已启动：http://0.0.0.0:8787/mcp
[weread-mcp] 鉴权：已开启 Bearer Token
```

### macOS / Linux

```bash
cd weread-mcp-worker/server
npm install
cp .env.example .env && vi .env      # 填两个值
npm run start:env
```

## 二·五、看板与共读（可选）

浏览器打开 `http://127.0.0.1:8787/dashboard?token=你的口令` 就是看板，双 Tab：**📖 共读** / **📚 书架与笔记**。
书架 Tab 直接可用；共读 Tab 需要导入一本原书：

> 打开看板 → **📖 共读** → **把 EPUB 拖进去**，浏览器本地拆段并自动保存到 `server/coread.json`。

不想用浏览器，就在本机跑一条命令：

```bash
python tools/coread-upload.py 你的书.epub --url http://127.0.0.1:8787 --token 你的口令
```

想换落点就在 `.env` 里设 `COREAD_FILE=D://某处//coread.json`。

**共读页只显示被批注过的段落**（🟡 你的 / 🔵 闻舟的思考）—— 整本原文不出现在页面上，它是给 AI 读的素材。
批注单独存 `server/coread-notes.json`（落点可用 `COREAD_NOTES_FILE` 改）。

- 共读页**不放**原文搜索框：原文是给 AI 经 MCP 读的、给人在微信读书里读的，页面只当批注看板
- 段落按**章节**分组，顶部有**章节目录条**：点一章跳到那章、点章标题就地折叠、右上角「全部收起 / 展开」（`第X部 / 第X章 / 序章 / 尾声 …`）；整本正文挤在一个 xhtml、文件标题又是「未知」的 EPUB，保存时会按正文里的章节标记**自动重切**
- 编辑器**保存成功就自动收起**；也可以点「收起」或再点一次段落关掉
- **同步你在微信读书的划线/想法**：点共读页顶部 **🔄 同步微信读书划线**（=`POST /coread/sync`），按书名匹配笔记本、按原文对齐段号 —— **想法**写进 🟡 栏、**划线**只作段落标记（黄边 +「你划过线」，**不会**变成你的评论）；🔵 闻舟批注不动
- 书名对不上（官方版 vs 别处下的版本 / 导入书标题变作者名）时不会硬凑：看板会列出**候选书单**，点一本即绑定记住（存 `coread-bind.json`）
- AI 读写原文与批注：`coread_outline` / `coread_read` / `coread_search` / `coread_annotate` / `coread_sync`

## 三、手机怎么连

### 场景 A：同一 Wi-Fi（最简单）

1. 查电脑局域网 IP：Windows `ipconfig`（找 `IPv4 地址`，形如 `192.168.1.23`）。
2. 手机 App 里填：`http://192.168.1.23:8787/mcp` + `Authorization: Bearer 你的口令`。
3. Windows 防火墙若拦截，放行 Node 的入站（或临时在「专用网络」放行 8787）。

> ⚠️ 很多 MCP 客户端对**远程服务器强制要求 `https://`**，纯 `http://IP` 可能被拒。被拒就走场景 B。

### 场景 B：内网穿透，拿一个 https 域名（推荐，手机随时可连）

电脑不暴露公网，只有你的隧道地址能进来。三种常见做法：

| 工具 | 一句话 | 备注 |
|------|--------|------|
| **Cloudflare Tunnel**（`cloudflared`） | 把 `127.0.0.1:8787` 映射成 `https://xxx.trycloudflare.com` | 免费、最省事；临时域名重启会变 |
| **Tailscale Funnel** | 装在电脑，`tailscale funnel 8787` | 免费、稳定，需要装 Tailscale |
| **frp** | 你已有 VPS 的话，frps 在 VPS、frpc 在电脑 | 可控性最强，配置略多 |

以 Cloudflare Tunnel 快速版为例：

```bash
cloudflared tunnel --url http://127.0.0.1:8787
# 它会给一个 https://xxxx.trycloudflare.com，那么 MCP 地址就是
#   https://xxxx.trycloudflare.com/mcp
```

> 想固定域名就绑你自己的域名做正式 Tunnel（Cloudflare 后台配 DNS 路由）。

### 场景 C：直连公网

给电脑/路由器做端口映射到 8787 + 自己配 https（自签或域名证书）。除非你很清楚风险，否则不建议——等于把你的微信读书数据端点直接挂到公网。

## 四、让它在后台常驻

### Windows

- **任务计划程序**：新建任务 → 触发器「登录时」→ 操作 `node`，参数 `src/server.js`，起始于 server 目录。
- 或装 **nssm / pm2** 当 Windows 服务跑：
  ```powershell
  npm i -g pm2
  pm2 start src/server.js --name weread-mcp
  pm2 save
  ```

### macOS / Linux

```bash
npm i -g pm2
pm2 start src/server.js --name weread-mcp
pm2 save && pm2 startup
```

## 排错

| 现象 | 处理 |
|------|------|
| `未配置 WEREAD_API_KEY` | `.env` 没被读到：Node < 20.12 不支持 `--env-file`，改用环境变量或 `npm start` + 手动 export |
| 手机连不上局域网地址 | 防火墙没放行；或手机不在同一网段；确认 `HOST=0.0.0.0` |
| 客户端提示"必须 https" | 走场景 B 的内网穿透拿 https 地址 |
| 端口被占 | 改 `.env` 的 `PORT`，或结束占用 8787 的进程 |
| 调用工具报 `errcode` | 网关侧问题（key 失效 / 需升级 `skill_version`），看返回 errmsg |
